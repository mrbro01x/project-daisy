## 📖 About Project Daisy

**Project Daisy** is an open-source repository dedicated to preserving and sharing pristine, professionally formatted EPUB editions of classic literature. 

While public-domain digital libraries are widely available, many suffer from formatting inconsistencies, OCR artifacts, broken internal navigation, or poor typographic standards. Project Daisy solves this by delivering clean, standards-compliant, and beautifully typeset EPUB 3 files designed for an optimal reading experience across all modern e-readers and applications.

---

## ✨ Key Features

* **Typographic Precision:** Clean XHTML/CSS styling, accurate punctuation, and support for advanced digital typography standards.
* **Flawless Navigation:** Fully verified NAV and NCX documents ensuring seamless table-of-contents support, chapter jumping, and bookmarking.
* **Cross-Device Compatibility:** Tested for flawless rendering on major reading platforms (Apple Books, Calibre, KOReader, Google Play Books, and dedicated e-ink devices).
* **Open Source & Accessible:** Freely accessible for personal reading, archival, and community-driven curation.

---

## 📥 Access & Usage

You can download any `.epub` file directly from this repository and open it using your preferred e-reader. If you use **Calibre**, these files can be easily synced to your mobile device or e-ink reader without any conversion issues.

## 🤝 Contributing

Contributions to improve existing texts or add new public-domain classics are always welcome!

1. Ensure your EPUB file adheres strictly to EPUB 3 standards and is free from transcription errors.
2. Fork the repository.
3. Create your feature branch (`git checkout -b feature/AddClassicBook`).
4. Commit your changes (`git commit -m 'Add [Author] - [Book Title]'`).
5. Push to the branch (`git push origin feature/AddClassicBook`).
6. Open a Pull Request.
